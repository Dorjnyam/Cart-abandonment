# Давамгай шалтгаан

Давамгай шалтгааны дүрэм:

```text
dominant_reason = argmax(S1, S2, S3, S4, S5, S6, S7)
```

UC1 дээр rage click, JavaScript error, slow page load өндөр тул `S2 Technical friction` давамгай болно.

UC3 дээр өндөр cart_total, shipping_cost, coupon failure, discount байхгүй тул `S5 Price sensitivity` давамгай болно.
