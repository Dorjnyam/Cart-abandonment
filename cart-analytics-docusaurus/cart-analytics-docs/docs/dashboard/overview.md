# Overview

Overview хэсэгт дараах KPI харагдана:

- Нийт сесс
- Сагс орхилтын хувь
- Амжилттай худалдан авалт
- Давамгай шалтгаан
- Загварын хувилбар
- Таамаглалын магадлал

Normal mode-д dashboard Main API-аас ирсэн бодит өгөгдлийг ашиглана. `NEXT_PUBLIC_MOCK_FALLBACK=true` биш бол mock data харагдах ёсгүй.
