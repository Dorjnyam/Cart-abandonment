# Environment тохиргоо

`.env.example`-ийг эхлэл болгон ашиглана. Secret утгуудыг repo-д commit хийхгүй.

Important variables:

- `KAFKA_BOOTSTRAP_SERVERS`
- `DATABASE_URL`
- `REDIS_URL`
- `DEMO_OBSERVER_API_KEY`
- `NEXT_PUBLIC_API_URL`
- `NEXT_PUBLIC_MOCK_FALLBACK`
- `GEMINI_API_KEY`

`NEXT_PUBLIC_MOCK_FALLBACK=true` нь зөвхөн frontend development-д зориулагдсан.
