# Хязгаарлалт

Энэ системийг thesis MVP гэж тайлбарлана. Production бүрэн баталгаа гэж overclaim хийхгүй.

- ML metric нь synthetic/simulated dataset дээр гарсан.
- LSTM нь active inference биш, future work.
- Dashboard normal mode нь Main API бодит өгөгдөл дээр тулгуурлана.
- Tenant isolation нь demo түвшний баталгаатай, production-grade multi-tenant security proof биш.
- Latency, uptime, SLO, scalability load test тусдаа хэмжигдээгүй.
- Gemini API unavailable үед deterministic fallback recommendation хэрэглэгдэнэ.
