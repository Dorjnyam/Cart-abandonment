# Secrets

Secrets-ийг repo-д commit хийхгүй. `.env.example` зөвхөн placeholder агуулна.

Defense-ийн өмнө шалгах зүйл:

- `.env` файл git-д ороогүй байх.
- Real API key илрээгүй байх.
- Demo key нь demo purpose гэдэг нь docs-д тодорхой байх.
- Rotation plan тайлбарлахад бэлэн байх.
