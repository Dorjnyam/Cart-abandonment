# Cart Analytics Demo Frontend

Энэ хавтас нь Cart Analytics dashboard-ийн Vite/React demo хувилбар юм. Үндсэн dashboard нь `cart_analytic/` дотор байгаа бөгөөд энэ project нь UI санаа, page layout, local preview хийхэд ашиглагдана.

## Ажиллуулах

```bash
npm install
npm run dev
```

## Environment

Gemini ашиглах шаардлагатай бол `.env.local` дотор key өгнө.

```env
GEMINI_API_KEY="your-gemini-key"
APP_URL="http://localhost:5173"
```

Key-ийг repository-д commit хийхгүй.
