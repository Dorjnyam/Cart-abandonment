5. Honest limitations
The reported ML result is controlled MVP validation on a synthetic/simulated dataset. It must not be described as real customer performance. The feature vectors are engineered synthetic behavioral signals, and the recommendation text is deterministic fallback logic unless Gemini is configured. Real/public clickstream validation should be reported separately if added later.
